# Bug Report

**Title**: `Spatial.reach_of()` collapses every class's basic-attack reach to the same 9.6 units, regardless of channel
**ID**: BUG-0001
**Severity**: S2-Major
**Priority**: P2-Next Sprint
**Status**: Open
**Reported**: 2026-08-04
**Reporter**: qa-lead (stream G · QA/determinism, spatial rebuild fan-out)

## Classification
- **Category**: Gameplay / Logic
- **System**: Spatial layer — reach gating (`monster-tamer/scripts/spatial.gd`)
- **Frequency**: Always — deterministic, no seed dependency. Reproduces on every call.
- **Regression**: Not a regression against a previously-working Godot build (the spatial layer is

## Reproduction Steps
**Preconditions**: `monster-tamer/scripts/spatial.gd` present (it is, as of this report).

1. Preload `res://scripts/spatial.gd`.
2. Call `Spatial.reach_of({"range": 3.0, "channel": "melee"}, true)` — the Tank/Warrior/Rogue/
   Generalist class-basic (melee band, per `data.json`'s `classBasic` table).
3. Call `Spatial.reach_of({"range": 8.0, "channel": "ranged"}, true)` — the Ranger/Stalker basic.
4. Call `Spatial.reach_of({"range": 7.0, "channel": "magic"}, true)` — the Wizard/Evoker basic.
5. Call `Spatial.reach_of({"range": 6.0, "channel": "support"}, true)` — a support-band basic.
6. Call `Spatial.reach_of({"range": 6.0, "channel": "voice"}, true)` — the Sage/Orator/Bard/
   Shaman/Mystic/Herald basic.

**Expected Result**: Five different reach values, differentiated by channel — matching
`CLAUDE.md`'s documented design ("melee 3.0 · ranged 8.0 · magic 7.0 · support 6.0") lifted onto
the new ground scale, analogous to how `CHANNEL_RANGE` differentiates melee(12.0)/ranged(32.0)/
magic(28.0)/voice(26.0)/support(24.0).

**Actual Result**: All five calls return **9.6** — `HARD_REACH_MIN`. A Ranger's bow and a Tank's
fists resolve to the identical stand-off distance for their free attack.

## Technical Context
- **Likely affected files**: `monster-tamer/scripts/spatial.gd` (`reach_of()`, line ~99-106).
  Downstream, once built: `spatial_sim.gd` (stream A) and `spatial_ai.gd` (stream B), both of
  which will call `reach_of()` with `is_basic=true` for every unit's default action — this is not
  a rare code path, it fires on essentially every tick of every fight.
- **Related systems**: `data.json`'s `classBasic` table (the data source for the authored ranges
  used above — verified directly, 19 classes, ranges of 3/6/7/8 depending on channel).
- **Possible root cause**: `reach_of()`'s `elif not is_basic:` guard skips the `REACH_SCALE`
  lift when `is_basic == true`. `classBasic` ranges are authored on the OLD 40×22 board scale —
  same as every other authored range, per the comment directly above the guard ("Authored ranges
  live on the pool's ORIGINAL 40×22 scale; lift them to the new ground") — but the guard was
  written as if `is_basic` implied "already correctly scaled," which it does not. All four raw
  values (3/6/7/8) fall below `HARD_REACH_MIN` (9.6) and clamp to the same floor, destroying the
  channel information before the caller ever sees it.

## Related Issues
- `CLAUDE.md`, "Battle sim (`src/battle.ts`)" section: documents this *exact* failure mode
  being found and fixed twice already in the TypeScript engine — first as "derived from whichever
  damage move a monster happened to draft" (a ranged monster getting an unreachable melee basic),
  then as "a second copy" of the same mistake inside `reachOf` itself. This Godot port is a third
  occurrence of the same bug class in a third location.
- `docs/SPATIAL_HANDOFF.md` §4 (stream A): "A unit may only act when the target is inside
  `Spatial.reach_of(move)` — reach gating is the entire point of the exercise." This bug makes
  that gate uniform-and-wrong specifically for the action every unit uses most.
- `docs/SPATIAL_QA.md` §5: notes that the planned reach-gating verification test (checking no
  shot exceeds `reach_of()` for the move used) will *pass* against this bug once `spatial_sim.gd`
  lands, because every basic will "correctly" clamp to 9.6 — the gate will be self-consistent but
  wrong. Fix this bug before trusting that check's green result for basic attacks.
